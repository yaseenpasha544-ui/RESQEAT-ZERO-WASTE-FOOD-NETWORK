Project Overview

Website Category: Social Impact · Food Donation · Sustainability

Problem Statement: Large quantities of edible food are wasted while many people go hungry. ResQEat connects food donors with nearby NGOs and families through a real-time platform.

Why this project? To reduce food waste, help communities, and demonstrate how thoughtful web design and engineering can solve real-world problems.

Project Description

ResQEat is a responsive frontend web application where restaurants, hotels, bakeries, supermarkets, and households can post surplus food. Nearby NGOs and families can search, filter, and claim donations quickly — with an at-a-glance countdown ring showing how urgently each listing needs to be claimed. The site includes a donation form, a live donation feed with filtering, an animated impact dashboard, and full dark mode support.

Key Features

  • Responsive, mobile-first UI with scroll-triggered animations
  • Donation form with inline validation
  • Live donation feed with search and urgency filters
  • Visual countdown rings that reflect time remaining
  • Dark / light mode with saved preference
  • Animated impact dashboard with a rotating highlight slider
  • Toast notifications instead of blocking alerts

Future Improvements

  • AI-based expiry prediction
  • GPS-based proximity matching
  • User authentication for donors and NGOs
  • Cloud database for persistent, shared listings
  • Volunteer management and delivery coordination
  • QR code verification for handoffs
